Interactive Hybrid Urban Generation.

Combining modular rules with volumetric continuity and interactive control.

Date
October – December 2025
Context
UCL / Digital Studio
Group project
Methods
Wave Function Collapse, Marching Cubes, Grasshopper, C#, Unity

My contribution

Concept development; modular design; baseline system development; Wave Function Collapse implementation; C# and Unity development; technical drawings.

From algorithmic output to user agency

This project combines Wave Function Collapse and Marching Cubes to explore how procedural systems can generate varied urban environments while retaining spatial coherence. Adjacency rules and socket-based constraints establish the modular logic of the initial system.

Marching Cubes introduces volumetric continuity beyond the limitations of discrete modules. A hybrid Grasshopper–Unity workflow adds an interaction layer, allowing users to influence the generated configurations. The resulting catalogue explores variation in height, massing, spatial organisation, and architectural character.
